# Режимы и практика

Запускайте `Assets/Scenes/Startup.unity`. После проверки JSON/изображений меню предлагает:

- **Обучение**: пять вводных шагов в существующем кабинете: слой, наведение, захват, отпускание, исследовательская зона. Это вводный сценарий управления, а не полный курс анатомии.
- **Изучение**: существующий кабинет с моделями, подносом, монитором и изображениями.
- **Практика**: выбор сложности, затем набора и переход в `Assets/Scenes/PracticeScene.unity`.

Практика содержит ту же комнату со своим запечённым освещением, стол сборки и отдельный стол с деталями. Компьютера, исследовательской зоны и галереи здесь нет. Меши, материалы, коллайдеры, столы и цели сохранены в сцене. При запуске выбранные детали раскладываются на столе без пересечений; лишние выключаются. Интерфейс создаётся кодом.

## Сложность

- **Начальный**: полупрозрачные контуры незаполненных мест, название при наведении/захвате, подсказка следующей или удерживаемой детали. Контур удерживаемой детали становится ярче.
- **Средний**: названия при наведении/захвате; контуров и подсказки расположения нет.
- **Продвинутый**: названия и контуры скрыты. Остаются общий прогресс, время и сообщения о результате установки.

Наборы: **Кости — 10**, **Мышцы — 17**, **Мозг — 9**, **Всё вместе — 36 физических деталей**. Парные части с одинаковым JSON ID имеют отдельные места установки. Зубы, кожа и глаза в эти наборы не входят. Русские названия поступают из существующего JSON через `ElementDog`; формат и файлы сервера менять не требуется.

## Сборка

Используются существующие руки/притягивание HurricaneVR. Деталь устанавливается при отпускании около собственного места с подходящим поворотом. Допуски по сложности: 10/7.5/6 см и 35/25/18 градусов. Проверяется также, что другая цель не ближе. Правильная деталь плавно закрепляется в сборке. Неправильно отпущенная возвращается на своё место на столе деталей и паркуется без гравитации. Неудачная установка возле стола сборки увеличивает счётчик ошибок.

Установленную деталь можно снова взять; прогресс уменьшается. Внутренние детали можно проводить через уже установленные части. Завершение отображается после установки всех выбранных деталей, таймер останавливается. Есть **Заново** и **В меню**; в редакторе Escape также возвращает в меню.

Рядом со столом сборки **Y** левого Quest-контроллера переключает управление моделью: левый стик вращает по преобладающей оси, правый меняет масштаб, **X** сбрасывает вращение, **A** сбрасывает масштаб. В этом состоянии движение стиками отключено. При выходе из зоны или режима управление игроком восстанавливается. Собранные части следуют за моделью.

## Устройство

`AppSession` хранит выбор и переключает сцены. При переходе перепривязывает постоянный HVRManager к новому игроку/камере. `StartupFlow` повторно использует уже загруженный сервис контента. Сцена практики включена в общий список сборки после Startup/SampleScene.

`PracticeSession` отвечает за набор, раскладку, подсказки, прогресс и интерфейс. `PracticePiece` — за захват, установку и возврат. `PracticeSlot` — за контур. `ReturningGrabbable` направляет безусловные HVR hooks в практику либо в прежний `OnMoveBackItem`, в зависимости от компонента объекта.

`Tools/Practice/Create practice scene` создаёт сцену только при её отсутствии. `Tools/Practice/Bake practice lighting` запекает открытую сцену практики. Эти команды не нужны для обычного запуска.

Проверки и ограничения записаны в `validation.txt`. Снимки — `output/practice/`. Проверка на физических контроллерах Quest и полноценная сборка APK в этой задаче не выполнялись.
