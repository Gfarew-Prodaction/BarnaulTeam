# Голова собаки

В SampleScene рядом с подносом сохранён объект `Dog Head · Layer Model`: 43 части из skull_muscles_textured123.fbx, Brain228.fbx и Skin.fbx. Геометрия и прозрачные силуэты находятся в сцене заранее. Мозг, глаза и кожный покров совмещены с головой по положению и масштабу. Это визуальная подгонка разных исходников, а не точная анатомическая регистрация.

## Слои

Панель переключает «Кожа», «Мышцы», «Кости», «Мозг». В режиме кожи отображаются кожный покров и глаза; в режиме мышц — только мышцы, в режиме костей — только кости и зубы. Все группы имеют общий центр вращения и масштаб. Уши объединены с кожей в исходном FBX. Зубы пока разделены только на две группы.

Подключены четыре оригинальные PNG-текстуры: головы, тела, пасти и шерсти. Файлы находятся в Assets/Models/DogHead/Textures; 10 материалов URP/Lit используют соответствующие карты цвета без коричневого множителя. Для шерсти включены Alpha Clipping, двустороннее отображение и запись глубины; прозрачность берётся из альфа-канала исходного PNG. Объект ger_shepherd_LOD0.003 включён в сцене. Оба экземпляра Skin.fbx в проекте имеют переназначение на эти материалы. Отдельный внутренний фрагмент покрова сохранён без выдуманного анатомического названия.

Повторное подключение: Tools → Dog Head → Apply supplied textures. Резервные копии прежних материалов — Backups/DogMaterials-before-textures; прежняя сохранённая сцена — Backups/SampleScene-before-textures.unity. Проверенный рендер — output/dog-textured-preview.jpg.

## Управление Quest

В пределах 1,6 м от VetTable кнопка Y включает/выключает управление моделью. При отходе режим выключается. В этом режиме ходьба, поворот игрока стиком и телепортация отключены; физическое отслеживание головы продолжает работать.

- Левый стик: вращение по горизонтали или вертикали с выбором доминирующей оси.
- X: сброс поворота к исходному положению сцены.
- Правый стик вверх/вниз: равномерное изменение масштаба, от 50% до 180%.
- A: сброс масштаба к исходному.

Кнопки слоёв нажимаются лучом любого контроллера и триггером. Панель принимает попадания с обеих сторон; надписи и декорации не перехватывают луч. Используется модуль HurricaneVR, конкурирующий модуль Input System на том же EventSystem отключается.

## Захват

На каждой части установлены ReturningGrabbable, ElementDog, ElementInfoPresenter, OnMoveBackItem, ElementInteractionVisuals, Rigidbody и упрощённый выпуклый MeshCollider. При наведении руки/силового захвата часть окрашивается зелёным только пока это текущая цель HurricaneVR и его проверки CanGrab/CanHover разрешают захват. При запрете захвата, выключенном дистанционном захвате, удержании, притягивании и потере цели зелёный цвет снимается. Название при наведении использует ту же проверку. При удержании части связанные элементы подсвечиваются янтарным: суффиксы .001 относятся к одной мышце; связаны также полушария, обонятельные луковицы и глаза. Связь действует внутри одной головы.

В исходном положении взятой детали появляется прозрачный силуэт. Он следует за поворотом и масштабом модели и исчезает после возврата. Деталь возвращается в сохранённую локальную позу, с учётом нового масштаба головы. Размещение на подносе и исследовательском столе сохраняет приоритет. После возврата можно снова захватить деталь.

## JSON

Актуальный файл: Documentation/RemoteContent/elements.example.json, версия 11, 37 записей. Встроенная копия — Assets/Resources/ElementContent/elements.json. У каждой записи четыре разные иллюстрации из атласов или учебных интернет-источников. Парные части с одинаковым анатомическим ID используют общую галерею. Если записи ещё нет на сервере, работает встроенный JSON; серверная запись с тем же ID имеет приоритет.

Актуальный полный архив: output/element-atlas-full-upload.zip. Он содержит 38 уникальных изображений галерей и одну дополнительную фотографию-иконку мозга. Всего 148 привязок в JSON: общие схемы используются для нескольких связанных элементов. Внутри каждой галереи проверена уникальность четырёх изображений, включая пиксельное содержимое. Виды 3D-моделей в новые галереи не включены. Обзорные схемы и технические фрагменты подписаны без выдуманных границ или выделений.

Для обновления сервера сначала загрузить содержимое images/ архива в element-content/images/, затем заменить data/elements.example.json. Перезапустить приложение с интернетом. Источники, страницы атласов, соответствия ID, контрольные суммы и превью включены в архив. Скрипт повторной упаковки: Documentation/DogHead/package_atlas_gallery.py (PyMuPDF и Pillow). Старые архивы сохранены для истории; использовать следует новый element-atlas-full-upload.zip.

## Проверка

Выполнены проверки Play Mode: привязка 43 частей к JSON, парковка активных Rigidbody, сохранённые силуэты, слои, блокировка/восстановление движения, вращение, масштаб и сбросы, подсветка пары/наведения, возврат после изменения модели и повторный захват. Успешно скомпилирована сборка игровых C#-скриптов с Player-настройками; APK в этой проверке не собирался. Ввод контроллеров и события HVR имитировались; проверка в физическом шлеме остаётся необходимой.

Резервная копия прежней головы: Backups/SampleScene-before-head-v2.unity. Tools → Dog Head → Upgrade complete anatomy устанавливает новую модель в старую сцену; повторный вызов не создаёт дубликаты.


Глаза: геометрия приведена к масштабу кожи, центры совмещены с границами глазниц; обновлены коллайдеры и исходные позиции прозрачных образов. Процедура обновления модели сохраняет исправленную посадку.
