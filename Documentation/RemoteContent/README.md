# JSON-данные элементов

Данные: `ElementCatalog` содержит `version` и массив `RemoteElement`. Запись содержит `id`, `name`, `nameLatin`, `shortDescription`, `fullDescription`, `iconUrl`, `images` (title/caption/url; старый imageUrls также поддерживается). Это обычные сериализуемые C#-классы, без ScriptableObject. Картинки в JSON представлены только абсолютными HTTPS-ссылками; пустые значения допустимы.

## Запуск

Открывай Assets/Scenes/Startup.unity. StartupFlow создаёт persistent RemoteElementContent: проверка сервера → меню → SampleScene. Не добавляй второй загрузчик в игровую сцену. Для самостоятельной сцены добавь RemoteElementContent и при необходимости укажи Elements Root. Если корень не назначен, загрузчик связывает все ElementDog загруженной сцены, включая неактивные.

У каждого ElementDog укажи точный Id (например, capsule). Он хранит ID данных; возврат отдельно обрабатывает OnMoveBackItem. Имена GameObject больше не используются для сопоставления. Тексты и изображения на предмете не сериализуются.

- `element.Data` возвращает запись RemoteElement или null, если ID отсутствует.
- `element.Data.name`, `nameLatin`, `shortDescription`, `fullDescription` — текст для UI.
- `element.GetImage(element.Data.iconUrl)` — Sprite иконки из локального кеша.
- `element.GetImage(element.Data.imageUrls[index])` — изображение для галереи. Проверяй запись, массив и индекс перед обращением.
- `RemoteElementContent.ContentChanged` — уведомление о замене каталога. Отписывай обработчики при отключении UI.
- `Refresh()`, `Status`, `Progress`, `LastError`, `IsUpdating`, `InitialCheckComplete` доступны экрану загрузки.

## Сервер

Каталог: https://zgmwmaustzdsqybamalu.supabase.co/storage/v1/object/public/element-content/data/elements.example.json

Загрузи обновлённый Assets/Content/elements.example.json в Supabase по тому же пути. Он содержит heart и capsule (версия 2). Загрузка файлов на сервер из приложения не производится. Приложению не нужны ключи Supabase для публичного bucket.

Каждый запуск скачивает JSON и сравнивает SHA-256 текста. Одинаковый JSON не скачивает изображения повторно. При изменении JSON скачивается весь новый набор изображений, затем атомарно переключается активный кеш. Поле version информационное. Для изменённой картинки используй новый URL (например, heart-v2.jpg) и обнови JSON. Замена картинки без изменения JSON не обнаруживается.

## Кеш и отсутствие сети

Кеш: `Application.persistentDataPath/ElementContent`. При запуске читается последний сохранённый каталог. Если кеша нет, загружается встроенный JSON `Assets/Resources/ElementContent/elements.json`. Его можно заменить через Fallback Catalog на компоненте. Это тоже JSON, не набор ScriptableObject. Базовый файл позволяет показать демо-тексты при первом запуске без сети; удалённые изображения становятся доступны только после успешного скачивания.

Серверный каталог полностью заменяет базовый. Записи не смешиваются: если сервер прислал только heart, у capsule Data будет null, а карточка покажет имя объекта и отсутствие описания. Встроенный JSON и пример для сервера нужно менять согласованно при добавлении новых элементов.

Ошибка обновления оставляет прежний набор активным. Удаление приложения/очистка данных удаляет кеш. Старые наборы на диске пока автоматически не удаляются. Изображения создаются по запросу и кешируются по пути набора + URL. Старые Sprite остаются валидными для открытого UI до уничтожения загрузчика. Для большого каталога потребуется лимит памяти/диска.

На Android нужен Internet Access → Require; не включай Force Remove Internet Permission в настройках OpenXR Meta Quest Support. Используй изображения разумного размера (например, до 2048×2048).

Проверка на устройстве: первый запуск онлайн, повтор без интернета, обновление JSON, ошибка изображения и повторная загрузка. Компиляция проверена; полный цикл на Quest ещё требует проверки.
