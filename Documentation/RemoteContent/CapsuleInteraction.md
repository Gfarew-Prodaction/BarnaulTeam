# Capsule: наведение и карточка в руке

SampleScene → Capsule содержит CapsuleCollider, Rigidbody, ReturningGrabbable (наследник HVRGrabbable), ElementDog, ElementInfoPresenter и HurricaneInteractionSetup. Слой Grabbable (20) входит в существующие маски рук. HVRGrabbable.ForceGrabbable включён. Обычный захват, коллизии, притягивание и передача в руку остаются HurricaneVR.

HurricaneInteractionSetup при старте переключает активные HVRForceGrabber сцены в штатный режим ForcePull без flick. Кнопки берутся из существующих HVRPlayerInputs (в текущем базовом риге ForceGrabActivation = Grip). Для возврата к Gravity Gloves убери этот компонент и настрой Grab Style на руках. Компонент не меняет исходные префабы HurricaneVR.

ElementInfoPresenter подписывается на HVRGrabbable.HoverEnter/HoverExit и учитывает обе руки и ForceGrabber. Это выбор предмета штатной рукой, а не наведение взглядом. Пока предмет в руке (IsHandGrabbed), показывается одна информационная карточка. После отпускания карточка скрывается; название может остаться, если рука всё ещё выбирает предмет. UI без коллайдеров и без перехвата лучей. Размер и зазор настраиваются в компоненте. Панели имеют постоянный мировой размер независимо от масштаба Capsule, ориентируются на MainCamera, следуют за предметом и удаляются вместе с ним.

Данные берутся из ElementDog.Data (RemoteElement, обычная запись JSON). У Capsule id = capsule. Базовый каталог Assets/Resources/ElementContent/elements.json содержит демонстрационную запись capsule. Для онлайн-работы загрузи Assets/Content/elements.example.json в Supabase: серверный каталог полностью заменяет базовый. Если записи capsule нет, карточка показывает имя объекта и сообщение об отсутствии описания. Скрипт обновляет видимую карточку при замене записи. Иконка загружается из кеша через URL. ScriptableObject для контента не используется.

Оформление: тёмный блок со скруглением, белое название, приглушённая латынь и бирюзовый акцент по приложенному изображению. Google share-ссылка недоступна из инструмента просмотра, её содержимое не использовалось.

Проверка: запусти Startup → меню → SampleScene либо напрямую SampleScene. Наведи контроллер на Capsule → название. Активируй distance grab (Grip в базовых настройках) → предмет притягивается. Возьми близко рукой → карточка. Передай в другую руку → карточка остаётся. Отпусти и убери обе руки → UI скрывается. Проверка компиляции и структуры сцены пройдена; физика, видимость шрифтов и hover на Quest требуют проверки в Play Mode/на устройстве.

## Возврат на старт

На Capsule установлен OnMoveBackItem. Он один раз в Awake запоминает мировые позицию и поворот Rigidbody. После окончательного отпускания предмет возвращается к сохранённой позе за 0.5 секунды. Отдельная точка/ссылка больше не используется. При передаче между руками или из force grab в руку проверка откладывается на кадр. Повторный захват прерывает возврат. Отключение и включение компонента не меняет сохранённую позу.

В покое и при возврате Rigidbody кинематический, гравитация отключена. FreezeAll больше не используется. ReturningGrabbable восстанавливает динамику во внутреннем OnBeforeGrabbed, который HurricaneVR вызывает даже при передаче с выключенными UnityEvent. Внутренний OnReleased/OnGrabCanceled планирует возврат с задержкой кадр. При передаче force grab → рука или между руками возврат отменяется. Позиция и поворот в конце возврата точно устанавливаются в сохранённую стартовую позу.

Для других элементов используй ReturningGrabbable вместо обычного HVRGrabbable (не добавляй оба), Rigidbody и OnMoveBackItem. Начальную позу выставляй до Awake. Не ставь Is Kinematic в сцене заранее: базовый Awake HurricaneVR должен увидеть динамическое тело; режим покоя задаёт OnMoveBackItem.Start. Исходники HurricaneVR не изменены.
