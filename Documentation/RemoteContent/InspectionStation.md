# Зона исследования, монитор и фотографии

В SampleScene Cube (1) содержит ElementInspectionStation. BoxCollider используется как область размещения (trigger); исходный сплошной MeshRenderer выключен. При запуске под зоной появляется метка. При окончательном отпускании OnMoveBackItem сначала проверяет эту зону, затем поднос, затем возвращает предмет на старт. Только один элемент на станции. Объект закрепляется в зоне; повторный захват освобождает станцию и очищает информацию. Все исследуемые элементы должны иметь ReturningGrabbable, OnMoveBackItem и ElementDog с ID из JSON.

В Computer назначен Cube (2); UI создаётся на ближайшей к пользователю тонкой боковой поверхности монитора. Для этой модели толщина — локальная ось X. Monitor Size задаёт физический размер экрана. Название, латынь и полное описание берутся из RemoteElement. Кнопки «Выше/Ниже» прокручивают длинный текст.

Gallery Center назначен на Cube (2), компьютер; Radius и Height управляют расположением круговых превью над столом. Все фотографии текущего элемента показываются одновременно, без страниц и кнопок перелистывания. Возле каждого круга — title и caption. Клик открывает увеличенный снимок: за 0.68 с круг приближается, расширяется и превращается в скруглённую прямоугольную карточку, название и подпись проявляются после раскрытия. «Закрыть» за 0.48 с возвращает карточку в круг на текущем месте галереи. Контур и stencil-маска фотографии перестраиваются MorphPanelGraphic; используются UI-материалы Unity без пользовательского шейдера. Новое исследование закрывает старый просмотр. Круговые изображения обрезаются маской с сохранением пропорций.

## JSON

В элемент добавлен массив images:

    "images": [
      {
        "title": "Общий вид сердца",
        "caption": "Передняя поверхность",
        "url": "https://YOUR_PROJECT.supabase.co/storage/v1/object/public/element-content/images/heart-front.jpg"
      }
    ]

Локальные примеры обновлены до версии 3. Загрузить в Supabase нужно Assets/Content/elements.example.json. Вместо пустых url укажи реальные публичные HTTPS-ссылки на фотографии. Пустой url показывает заглушку, а не скачивает файл. Сейчас в примерах три заглушки на элемент. При замене снимка меняй его URL и JSON. Старый массив imageUrls поддерживается для совместимости; если заполнен images, галерея использует его. Загрузчик скачивает новые изображения вместе с каталогом до переключения кеша. Серверный JSON не обновляется из Unity автоматически.

## Управление

InspectionVRInput использует штатный HVRInputModule и HVRUIPointer. Canvas регистрируются и удаляются в модуле. Если модуль отсутствует, он добавляется на существующий EventSystem, а другие его InputModule отключаются на время этого запуска. Клик — Trigger, дистанция UI до 5 м. Используются указатели существующего рига; если их нет, добавляются указатели на HVRHandGrabber. Это контроллерное управление, а не ввод взглядом. Отдельная система захвата не создавалась. UI монитора и динамическая галерея строятся при запуске; поднос остаётся сохранённым в сцене.

Проверь на Quest: отпустить Capsule в зоне Cube (1) → имя/латынь/полный текст на Cube (2); фото и подписи из JSON; клик кругового фото → увеличение; закрытие; повторный захват → очистка; отпускание вне станции → поднос/старт; более шести фото → все присутствуют на кольце. Компиляция Editor/Player проверена. Визуальное размещение, raycast, физические переходы и сетевые фотографии на устройстве ещё требуют проверки.


Обновлённый стиль: фон #F2F9F9, основной текст #133845, бирюзовый акцент #097882 и приглушённый серо-синий текст. Галерея построена дугой вокруг компьютера, не вокруг подноса. Кольцо медленно вращается вокруг компьютера независимо от поворота головы. В SampleScene минимальный радиус 0.65 м, высота 0.45 м над центром компьютера. Orbit Speed = 2.5 градуса/с (оборот за 144 с), Bubble Gap = 0.06 м. При большом числе изображений радиус увеличивается автоматически с учётом ширины подписей и бокового покачивания. Каждый круг продолжает слегка покачиваться вверх-вниз и по радиусу и поворачивается лицом к пользователю. Смена элемента, снятие предмета и отключение станции прерывают анимацию и очищают просмотр. Google share-ссылка недоступна для чтения, поэтому точное совпадение с её палитрой не заявляется.

Кнопки перелистывания удалены. Раскрытие в карточку и обратная анимация сохранены: при закрытии изображение возвращается на актуальное место вращающегося кольца. Все фото доступны, пока выбран элемент на станции; при снятии элемента галерея очищается.
